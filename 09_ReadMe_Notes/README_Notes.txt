NovaPay FP&A Command Center - Project Notes

This project was built as an end-to-end finance analytics and FP&A portfolio project for a fictional fintech company called NovaPay. The main purpose was to create a clean business reporting workflow that starts from raw data and ends with an interactive Power BI dashboard, executive report, and presentation.

The project uses monthly business data from January 2024 to June 2024. The dataset includes revenue, budget, expenses, customer details, KPI metrics, scenario assumptions, and a date table.

Work completed:

1. Raw Data Preparation
The raw CSV files were organized for revenue, budget, expenses, customers, KPI metrics, and scenario inputs. The files were cleaned and checked so they could be used consistently across Excel, SQL, Python, and Power BI.

2. Excel Financial Model
The Excel model was created to organize the financial data into structured sheets. It includes revenue data, customer data, budget data, expense data, KPI data, scenario inputs, and a date table. The model was used as the base finance file for the project.

3. SQL Analysis
SQL queries were created to analyze business performance. The SQL file includes queries for revenue trends, budget comparison, expense review, KPI tracking, customer-level revenue, and performance summaries.

4. Python Forecasting and Analytics
Python was used for trend analysis and forecasting support. The notebook helps review revenue movement, customer behavior, risk flags, and business performance patterns using the available monthly data.

5. Power BI Dashboard
The Power BI dashboard was built as the main interactive output. It includes KPI cards, a month slicer, revenue trend, budget vs actual revenue comparison, expense breakdown, customer revenue ranking, gross margin trend, and CAC trend.

6. Executive Report
A written executive report was created to summarize the project objective, data used, completed work, dashboard explanation, key insights, and business recommendations.

7. Presentation
A PowerPoint presentation was created to explain the project in a clean executive-style format. It summarizes the business problem, tools used, workflow, dashboard output, insights, and recommendations.

Main dashboard features:

- Month slicer for filtering dashboard results from Jan-24 to Jun-24
- Total Revenue KPI card
- Gross Margin % KPI card
- EBITDA KPI card
- Active Customers KPI card
- Churn Rate % KPI card
- Monthly Revenue Trend line chart
- Budget vs Actual Revenue chart
- Expense Breakdown by Category donut chart
- Revenue by Customer bar chart
- Gross Margin Trend line chart
- CAC Trend line chart

Key insights:

- Revenue increased overall from January 2024 to June 2024.
- EBITDA remained negative because operating expenses were higher than revenue.
- Gross margin showed a slight downward trend during the period.
- Payroll and marketing were the largest expense categories.
- A small number of customers contributed a major share of revenue.
- CAC increased during growth months, so acquisition efficiency should be monitored.

Business recommendations:

- Control major operating expenses, especially payroll and marketing.
- Improve EBITDA by increasing revenue and managing cost growth.
- Monitor CAC regularly to make sure customer acquisition remains efficient.
- Reduce customer concentration risk by expanding the customer base.
- Use the dashboard as a monthly reporting tool for faster management decisions.
